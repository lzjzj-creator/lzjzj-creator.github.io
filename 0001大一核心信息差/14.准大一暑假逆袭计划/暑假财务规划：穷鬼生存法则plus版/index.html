暑假财务规划：穷鬼生存法则plus版我知道你们看到这个标题会想什么——“我才刚高考完，你就跟我说财务规划？”但我要告诉你一件事：大学第一个月是最容易超支的时候。为什么？因为你手里第一次有了”巨款”——学费、生活费、还有七大姑八大姨给的升学红包，加在一起可能有几千块甚至上万。然后你进了大学，发现有太多东西要买：日用品要买吧？社团要交费吧？室友要聚餐吧？班级要团建吧？第一个月花超了，然后呢？然后你就开始吃土，或者不得不跟父母再要钱——这件事，想想就很丢人。所以，趁着暑假，先把自己的财务观念捋一捋。开学前的财务准备：兵马未动，粮草先行到底要带多少钱？很多人问过我这个问题，我的回答是：第一个月 = 正常月份的3倍。这不是我瞎说的，是我大一第一学期血淋淋的教训总结出来的。第一个月之所以要准备这么多，是因为你要一次性支付很多”首月专属费用”：被褥要买吧？桶盆衣架要买吧？插座台灯要买吧？社团入会费、班级班费、室友破冰聚餐……零零碎碎加起来，轻轻松松破千。我给你算一笔账，这是我自己用过的清单：大一开学首月额外支出清单：

被褥套装（学校买贵，网上买）：200-400元脸盆、桶、热水壶：50-80元洗衣液、洗发水、沐浴露：100-150元衣架（20个起）、夹子：30元排插（必须买好的，安全第一）：50-80元台灯（必须买，宿舍断电后全靠它）：50-100元桌面收纳、挂钩：50元社团入会费：100-300元班级/宿舍破冰聚餐：100-200元合计：730-1390元

这就是为什么我强烈建议你：第一个月的生活费预算，要按照正常月份的2.5-3倍来准备。如果你平时月生活费是1500，第一个月建议准备4000-4500元。如果你是2000，就准备5000-5500元。这笔钱不是让你乱花的，是让你有底气度过适应期。银行卡办理：这件事99%的人会踩坑到了大学，第一件事是什么？办卡。我见过太多人，大一上学期还在用家里的卡，父母转账要手续费，自己取钱要手续费，微信支付宝绑的卡还是异地的——光手续费一年下来都能喝十几杯奶茶。我的建议是：到了学校，第一时间办一张本地银行卡。优先选择学校绑定的那个银行，一般录取通知书里会写。如果没有指定，就办一张中国工商银行或者招商银行的卡，这两家网点多、转账免费、手机银行好用。办卡需要什么材料：

身份证（这个你肯定有）录取通知书（有的银行要，有的不要）学生证（等开学后）

办卡的时候，记得跟柜员说开通手机银行，不然你每次查余额都要跑ATM机，很麻烦。还有一个坑要提醒你：不要同时办太多张卡。我大一的时候被银行工作人员忽悠，一口气办了四张卡——结果这张卡年费10块，那张卡每季度收小额账户管理费，乱七八糟加起来一年扣了我快100块。卡多不是好事，两张三张就够了。微信支付和支付宝：学生优惠别忘了开通现在的大学生，应该没有人还在用现金了吧？微信支付和支付宝不光是付款工具，它们还有很多学生专属优惠，你不用就亏了。支付宝学生认证：打开支付宝 → 我的 → 头像 → 账号与安全 → 身份认证 → 选择”大学生认证”认证完成后，你可以享受：

海底捞6.9折（周一到周五，不含节假日，这个太香了）瑞幸咖啡免费券（经常有活动）滴滴出行学生优惠（每月至少省20块）京东学生专属价淘票票学生票（电影票便宜5-15块）

微信支付学生优惠：微信虽然学生优惠没有支付宝多，但有一个功能很实用：微信支付有学生地铁卡，各城市政策不同，可以省30%-50%的地铁费。校园一卡通（校园卡）：这个卡是你在学校里吃饭、借书、洗澡、进图书馆的全能卡。我的经验是：不要往里充太多钱。每次充200-300块就够了，充太多万一丢了心疼。我大一第一学期丢了两次卡，第一次丢了200，第二次丢了150，加起来350块，够我吃一个月食堂了。充值渠道：支付宝/微信搜索”校园一卡通”小程序，或者学校的APP。月度预算模板：直接抄作业就行我知道很多人看到”预算”两个字就头疼，觉得太复杂了。别怕，我给你弄了一套拿起来就能用的预算模板，三个档次，直接对号入座。1500元/月预算这个预算在大城市偏紧，但二三线城市勉强能活。固定支出（850元）：

食堂伙食：600元（早餐5元 + 午餐10元 + 晚餐10元 = 25元/天 × 24天 = 600元，剩下几天可能吃个泡面或者剩饭）日用品：100元（纸巾、洗衣液、洗发水均摊）话费+网费：50元（校园网30元/月 + 手机卡19元套餐）学习用品：50元（笔、本子、打印均摊）交通：50元（偶尔出门坐公交/地铁）

社交聚餐：200元（每两周一次AA，一次50-100元）零食奶茶：150元（控制在一周2-3杯奶茶）娱乐：100元（偶尔看场电影、打打游戏）衣服饰品：150元（一个月买一件平价衣服）

社交聚餐：350元零食奶茶：250元娱乐：200元衣服饰品：300元

强制储蓄：150元食堂生存指南：600块吃好一个月我知道你们看到”600块伙食费”的时候在想什么——“这是要修仙吗？”别慌，我手把手教你怎么吃。核心原则：早餐要吃好，午餐要吃饱，晚餐要吃少这句话不是养生鸡汤，是省钱秘籍。早餐是最便宜的，食堂的包子1块钱一个，豆浆1块5一杯，你花4块钱就能吃饱。但中午和晚上如果你点菜，一顿10块钱打不住。我自己的吃法：

早餐：两个包子 + 一杯豆浆 = 3.5元。或者一块钱一个的花卷，配上自己带的咸菜。偶尔奢侈一把，吃个煎饼果子，5块钱。午餐：打两个素菜 + 一两米饭 = 6-8元。素菜要选能吃饱的，比如土豆丝、炒豆芽、醋溜白菜。米饭一般2毛5一两，你可以打3两，5毛5。晚餐：跟中午差不多，或者更简单。我经常吃一碗面，5-8块。或者买两个馒头配老干妈，3块钱搞定。

这样算下来，一天伙食费大概18-22块，一个月550-660块。还有100块的余量，应对偶尔馋嘴或者跟同学AA买个大菜。外卖 vs 食堂：真实成本对比我大一上学期天天点外卖，第二学期开始吃食堂。给你算一笔账：点外卖的真实成本：

一份外卖平均价格：20-25元加上配送费（即使有红包也要2-5块）：23-28元一个月30天全点外卖：690-840元

吃食堂的真实成本：

一顿饭平均价格：8-12元一天两顿（早餐单独算）：20-24元一个月30天：600-720元

差价：每月多花90-240元，一年就是1080-2880元。这些钱够你买一双球鞋、考一次雅思报名费、或者暑假的来回机票。我知道外卖确实好吃，确实方便，但等你月底吃土的时候，你会怀念食堂的。校门口菜市场：隐藏的省钱宝藏每个大学附近都有一个菜市场，这是很多人都不知道的秘密。我大三的时候发现，学校后门出去走五分钟有一个菜市场。那里卖什么？

水果比水果店便宜30%-50%（同样一箱苹果，超市20块，菜市场12块）早餐原料：馒头、花卷、包子皮，回家自己热一下，比食堂便宜一半零食：散装饼干、散装瓜子，比超市便宜太多了矿泉水：一箱24瓶的矿泉水，菜市场15块，超市要25块

我室友说我”买菜的穿搭和阿姨一模一样”，但我一个月在零食水果上省下的钱，够买两本专业书了。“我快没钱了”紧急预案说出来你可能不信，月光族是大学里最常见的现象。我大一下学期就月光过两次，那种感觉——兜里只剩23块钱，距离父母打生活费还有11天——我现在想起来都头皮发麻。5个破产预警信号如果你出现以下任意3个，说明你快没钱了：

花呗/白条用了超过70%的额度开始用花呗套现来还花呗食堂只能打米饭和免费汤室友聚餐/社团活动你都在找借口不去你开始频繁查看余额，但越看越慌

紧急止血清单（按优先级）第一时间要砍掉的：

外卖——从今天起只吃食堂，不接受反驳奶茶/咖啡——一杯15块的奶茶，等于三顿饭的米钱冲动网购——把购物APP卸载了，想买的东西加入购物车，一周后再看会员订阅——视频会员、音乐会员，全部暂停

可以保留的（最低限度）：

食堂伙食——这个不能砍，身体是革命的本钱话费网费——断了就失联了学习用品——打印、买笔这种，不能影响学业

跟父母要钱的正确姿势我知道，“跟父母要钱”这件事对很多人来说是很难开口的。尤其是你已经要过一次，父母问”钱花哪儿了”的时候。我的经验是：不要等到弹尽粮绝了才开口，提前一周说。你可以这样说：“爸/妈，我这个月有点超支了，可能需要你再给我转500块。这个月主要是XX（社团聚餐/买了个XX/手机膜碎了换了新的），下个月我会注意的。”不要觉得这丢脸。父母宁愿多给你钱，也不愿意你饿肚子。但你要诚实，不要明明是乱花的，非说是交了学费。父母又不傻，你骗他们一次，他们就会怀疑你一辈子。没钱的羞耻感：我懂我知道有些人会觉得”我成年了还跟父母要钱，很丢人”。我想跟你说：你还在读书，没有收入来源，跟父母要钱是天经地义的事。我见过有人为了”不跟父母要钱”，去借网贷，去做不靠谱的兼职，最后欠了一屁股债。就为了那点面子，值得吗？大学四年是你积累资本的时期，不是你证明自己”独立”的时期。等你毕业了，一个月赚几千块的时候，再来谈独立也不迟。兼职指南：怎么赚钱不踩坑校内兼职：稳如老狗校内的兼职安全性高、路程近、时间灵活，是大一新生的首选。图书馆助理：

工作内容：整理书架、帮同学找书、登记借阅月薪：400-600元（勤工俭学岗位）优点：可以边工作边看书，环境安静缺点：有点无聊，可能要站一天

宿舍管理员助理（宿管阿姨帮手）：

工作内容：帮宿管做登记、收发快递通知月薪：300-500元优点：时间短，活儿轻松缺点：跟宿管阿姨打交道需要点情商

食堂帮工：

工作内容：打饭、收盘子、后厨帮忙月薪：管饭 + 500-800元优点：省钱，吃得好缺点：饭点最忙，而且有油烟味

家教：

这是我最推荐的兼职，没有之一行情价：

小学生：50-80元/小时初中生：80-120元/小时高中生：100-150元/小时一线城市价格更高，可以上浮30%-50%

优点：既能赚钱又能巩固知识，时薪最高怎么找：

学校家教中心（最靠谱，学校背书）熟人介绍（学长学姐推荐）正规平台（家长帮、家有学霸）

校外兼职：小心驶得万年船如果你想做校外兼职，一定要记住这10条防骗指南：

要交押金的一律不去——正规兼职不会让你先交钱押金、服装费、培训费全都不交——这些都是骗钱的套路日结工资太高的要警惕——比如”打字员日赚500”，肯定是假的身份证原件不能给——只提供复印件，复印件上写”仅用于XXX”签订书面协议——口头承诺不算数去偏僻地方面试要小心——最好有人陪同或者告知朋友先交体检费的不去——正规公司会报销体检费高薪诱惑的模特/主播要三思——很多是骗违约金的微商代理/直销不要碰——会先让你囤货，最后全砸手里遇到可疑立刻跑——损失的钱大概率追不回来，但至少不会被骗更多

时间价值计算：你的时间到底值多少钱我见过有人为了50块钱一小时的兼职翘课，我觉得这笔账完全算反了。来，我教你算：举例：你翘了一节高数课去做兼职，时薪50块。表面看：你赚了50块。实际上：

高数课缺勤一次，你可能要花2小时自己补期末挂科了，补考费80元，重修费200元挂科记录影响保研/出国/奖学金申请，损失可能几千上万

结论：这堂课的实际价值 = 50块（短期） vs 几千上万块（长期）我的建议是：逃课去做100块/小时以下的兼职，全是亏本买卖。所以我推荐家教，因为家教既能赚钱，又能顺便复习你的知识。你在教别人的时候，实际上是在帮自己巩固。这才是真正的时间价值最大化。技能型兼职 vs 体力型兼职我大一做过发传单、做过后厨、打包快递，全是纯体力活。时薪15-20块，干一天腰酸背痛。大二开始做家教，时薪80块。同样两小时，家教赚160块，发传单只赚30块。但这不是说体力兼职完全不能做。如果你现在急需用钱，没有时间学习新技能，先做一段时间体力兼职过渡是可以的。但不要一直做下去。我的建议是：做体力兼职的同时，用赚来的钱买一门技能课。比如你发了两个月传单赚了2000块，用这2000块去学Python、学剪辑、学摄影。下一步就做技能型兼职，时薪翻三倍不是梦。聪明花钱策略：省到就是赚到购物时间表：同样的东西，不一样的价格你知道吗？同一个商品在不同时间买，价格能差一倍。周一到周四：适合买生鲜、日用品超市、周黑鸭、烘焙店周一到周四客流少，会员折扣、生鲜打折活动基本在这几天。周五晚上：适合买电子产品和家电电商平台的促销活动经常从周五晚上开始预热，数码产品、家电在周五晚8点-周六价格最低。周二：适合买机票航空公司周二放特价票，周二查机票最便宜。不要在周五买机票，周五最贵。双十一/618：适合买大件如果你要买电脑、平板、相机、等大促买，能省15%-30%。但不要因为便宜而买不需要的东西。月末/季末：适合买衣服夏装季末清仓、冬天羽绒服打折都在季末这个时候。一件夏装T恤可能从99块降到29块。晚上8点-10点：适合买菜很多菜市场、超市晚上8点以后会打折处理当天没卖完的菜。便宜的离谱，但要注意新鲜度。二手市场：这些钱完全可以省大学四年，有些东西真的不用买新的。强烈推荐买二手的：

教材——学长学姐用完的，3折起步，能省70%。毕业季5月份大量出售，考完试立刻去买，不然被抢光了。自行车——校园里骑自行车是刚需，新车上500，二手车100-200搞定。台灯、电风扇、小风扇——这类东西用不坏，二手跟新的没区别。收纳盒、书架——二手小商品，5-10块一个。考研资料/考公资料——二手比全新的便宜太多。

可以考虑二手的：

电子产品——水比较深，如果不懂行可能被坑。如果买二手，要找信得过的学长学姐。耳机——入耳式的建议买新的，头戴式的可以考虑二手。正装/西装——就穿那么几次，二手完全够用。

记账系统：让每一分钱都有去处我知道你们看到”记账”两个字就想划走。但我告诉你，记账是所有理财的基础。 你不记，你永远不知道钱花哪儿去了。我见过太多人月末吃土，却说不清楚那2000块到底买了什么——“也没买什么啊，怎么就没了？”这就是不记账的后果。记账APP推荐我用过市面上主流的记账APP，给你排个序：第一名：MoneyWings（钱迹）

完全免费，无广告，无内购界面简洁，3秒记账支持自动导入微信/支付宝账单缺点：没有社交功能（其实这是优点）

第二名：随手记

功能最全，支持多人记账（适合情侣/室友合租）缺点：广告有点多，界面复杂

第三名：挖财

老牌APP，稳定缺点：最近广告越来越多

第四名：支付宝记账本

不用额外下载APP自动同步支付宝消费缺点：只能记支付宝的，微信的记不了

我的建议：MoneyWings + 支付宝记账本组合用。 一个记全面的，一个自动同步支付宝。各取所长。记账分类：你的每一分钱都要有名字很多人数记账太麻烦，是因为分类太复杂了。我建议分成这几类就够了：收入类：

父母给的生活费奖学金兼职收入其他收入（红包、退款等）

支出类——固定支出：

伙食费（食堂）外卖日用品话费/网费学习用品交通

支出类——灵活支出：

社交聚餐零食奶茶娱乐（电影、游戏）衣服饰品护肤美妆

支出类——偶发支出：

医药费电子产品人情往来（红包、礼物）旅游

每周复盘：5分钟改变财务命运记账的关键不是”记”，是**“看”**。每周日晚上，花5分钟做这件事：

打开记账APP，看这周花了多少钱分类排序，哪个类目花得最多问自己：这个类目可以少花多少？写下来，作为下周的目标

我给你举个例子：第一周复盘：

外卖：320元（超标了！正常应该150）奶茶：120元（4杯，太多了）社交：200元（正常）

下周目标：

外卖控制在150元以内，少点3次奶茶减到2杯，省60元

这样坚持一个月，你会发现自己钱包变厚了，整个人也有掌控感了。10%自动储蓄法：存钱无痛化每个月初，把生活费的10%自动转入一张不绑定任何支付软件的卡。1500元 × 10% = 150元2000元 × 10% = 200元2500元 × 10% = 250元这笔钱叫”保命钱”，除非生病住院，否则不动。等到毕业的时候，你会发现——不知不觉存了两三万。这可能是你第一笔完全靠自己的存款。说在最后我知道这篇文章看起来有点”老气”，像是我妈在唠叨”要省钱啊”。但我当年是真的吃过亏的。大一第一学期结束的时候，我算了算账，发现自己花了2万块——比我一学期的生活费还多了6000。那6000块是我妈后补的，她当时的眼神我到现在都记得，不是生气，是失望。从那之后我开始记账，每个月做预算，到现在毕业两年了，我每个月依然保持着记账的习惯。不是说我多省，而是我知道掌控感比有钱更重要。不是说你不能花钱，而是说，你要知道自己的钱花在哪里、花了多少。这样你才能真正做金钱的主人，而不是被钱推着走。从今天开始，下一个记账APP，不难的。你不需要成为理财专家，只需要比周围人多那么一点点的规划意识，四年下来，你存下的钱、避开的坑，会让你比大多数人都从容。共勉。
