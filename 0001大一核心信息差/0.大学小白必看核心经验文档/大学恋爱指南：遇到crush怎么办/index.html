大学恋爱指南：遇到crush怎么办说实话，这个话题我其实没什么发言权。因为我大学四年都没有谈恋爱，一直是单身狗。但正因为是单身狗，我反而观察了很多恋爱案例，有了一些思考。今天分享给有需要的人。怎么判断是不是喜欢？生理反应

看到他/她心跳加速忍不住想看他/她在他/她面前会紧张

心理反应

经常想起他/她关注他/她的一切动态他/她和异性说话会吃醋

行为反应

找各种借口接近想让他/她注意到自己会因为他/她的态度影响心情

学姐踩过的坑大二的时候我对一个学长有好感，天天看他的朋友圈，分析他发的每一条动态。后来才发现，我喜欢的只是「我想象中的他」，根本不是真实的他。教训是：喜欢一个人之前，先多接触了解，不要脑补太多。

什么时候表白最合适？表白时机

确定对方也单身有过一定接触，互相了解对方给你积极的反馈不是在对方很忙/心情不好的时候

不要在

的时候表白。表白话术直接型：

恋爱影响学习怎么办？说实话，这个问题我没什么经验，但我观察到的案例告诉我：好的恋爱是互相促进的，不好的恋爱才会影响学业。健康的恋爱关系

不会因为对方耽误自己的事能理性看待学业和恋爱对方支持你学习不会因为你忙而闹脾气

不健康的恋爱关系

天天黏在一起，什么都不干情绪完全被对方控制对方不支持你学习为了对方放弃重要机会

学姐碎碎念我室友谈恋爱之后，成绩从班级前10掉到30名开外。原因就是：每天晚上视频到12点，早上起不来上课，周末约会没时间复习。好的恋爱不是天天黏在一起，而是各自努力，互相支持。

分手怎么处理？分手后的心态

允许自己难过 - 失恋是很正常的情绪不要否定自己 - 分手不代表你不够好不要急着找下一个 - 先处理好自己的情绪保持正常生活 - 吃饭、睡觉、学习都要继续

分手后该做什么

哭一场和朋友倾诉删掉/隐藏前任的联系方式把注意力转移到学习/兴趣上给自己设定一个「走出悲伤」的期限

单身的快乐说实话，写这部分的时候，我其实是在安慰自己。但单身真的有单身的快乐：单身的优势

时间自由 - 想干什么干什么精力集中 - 可以全力搞学业/事业财务自由 - 不用买礼物/约会情绪稳定 - 不会被对方影响心情认识更多人的机会 - 可以自由接触不同的人

单身时期做什么？

✅ 提升自己（外表+内在）✅ 培养兴趣爱好✅ 发展学业/事业✅ 经营友谊✅ 到处旅行看看世界

学姐碎碎念我虽然没谈恋爱，但我有很多好朋友，成绩也不错，存款也有几万块。每次看到别人秀恩爱的时候，我就会安慰自己：「我在积累资本，以后值得更好的人。」或者我就默默点一杯奶茶，犒劳自己单身的日子。哈哈，开玩笑的。但真的，单身没什么不好，把自己过好最重要。

学姐私房话说实话，大学要不要谈恋爱，没有标准答案。遇到合适的人就谈，没遇到就不谈。不要为了谈恋爱而谈恋爱，也不要因为单身而焦虑。大学四年最重要的是找到自己、成长自己。无论是恋爱还是单身，只要你在进步，就是在正确的路上。
